# 🧩 Mini Memory — Curso

## Clase 8 — kit de inicio: Estilo propio

No hay piezas nuevas — el juego ya funciona completo. Esta clase es para
hacerlo tuyo.

```bash
npm install
npm run dev
```

### Ideas para personalizar

1. **Colores**: en `tailwind.config.js`, cambiá la paleta `brand` (son los
   morados que se usan en todo el juego) por tus propios colores.
2. **Tipografía**: agregá una fuente de [Google Fonts](https://fonts.google.com)
   en `nuxt.config.ts` y usala en `assets/css/tailwind.css`.
3. **Tus propias cartas**: editá `assets/data/cards.json` — cambiá los
   emojis por el tema que elegiste en la Clase 1 (¡también podés usar
   texto en vez de emojis!).
4. **Reto extra** (opcional, para quien quiera ir más lejos): agregá un
   selector para elegir entre 2 o 3 temas distintos, reutilizando lo que
   ya sabés de `v-for` y de pasarle datos a `useMemoryGame`.

### Cierre del curso

Cuando termines, compartí tu pantalla y jugá la versión de un compañero.
¡Armaron el mismo juego, pieza por pieza, y cada uno lo hizo distinto!
